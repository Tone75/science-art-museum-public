# Third-party software

The browser application uses web-platform APIs. It ships without a framework, an external font file or a third-party image. The gallery art and map are generated by the numerical engine in this repository. The interface uses fonts already available on the visitor's system.

| Direct development dependency | Version | Upstream license |
| --- | --- | --- |
| [Vite](https://www.npmjs.com/package/vite/v/8.3.6) | 8.3.6 | MIT, with additional third-party notices in the package |
| [TypeScript](https://www.npmjs.com/package/typescript/v/7.0.2) | 7.0.2 | Apache-2.0, with additional third-party notices in the package |
| [Playwright](https://www.npmjs.com/package/playwright/v/1.65.0) | 1.65.0 | Apache-2.0 |

Dependencies are installed from the public npm registry. The lockfile records the resolved tarballs, integrity hashes, and available license identifiers for transitive packages. Refer to each installed package's license and notice files for its full terms. This snapshot does not vendor `node_modules`.
